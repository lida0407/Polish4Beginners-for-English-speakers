--- guide.js (#/guide and #/guide/<chapterId>) ---
Export `renderBlock(block, {rows, words} = {})` (returns a Node) in addition to the default view, because the course reuses it.
renderBlock:
- Spans: Polish spans -> ui.pl(t) (wrapped in <b> when b); other spans -> <b> or plain text.
- h -> h3. p -> <p>. list -> ul/ol. table -> h('div', {class: 'table-wrap'}, table with thead/tbody); honour `rows` by slicing.
- study -> a .chips wrap with one button (class 'chip') per entry (honour `words`): Polish text; clicking calls openWord({polish: entry}).
- dialogue -> ui.card with h3 title, each line as tappable(line, {tag: 'div'}), a small 'Play' button that speaks the lines in order, and the meaning in muted small text.
- exercise -> ui.card with the prompt as h3 and, per item, the question text, an <input class="input"> and a 'Check' button; on check (or Enter) show a verdict line under it using L.checkAnswer(typed, ...item.a, item.full): ANSWER_EXACT 'Correct', ANSWER_DIACRITICS 'Right, but watch the Polish letters: <full>', ANSWER_WORD_ORDER or ANSWER_CLOSE 'Almost: <full>', ANSWER_WRONG 'Not quite: <full>' (classes 'verdict ok' / 'verdict no'). This block manages its own small DOM updates (no ctx).
View:
- #/guide: ui.header(data.guide.title, {kicker: 'Reference'}), a short muted line 'The full guide, chapter by chapter. For step-by-step lessons with quizzes use the course.', a button to #/course, then the chapters as ui.row(`${id} · ${title}`, '→') in a .grid.grid-2 -> #/guide/<id>.
- #/guide/<id>: ui.header(chapter title, {back: '#/guide', kicker: `Chapter ${id}`}), all blocks inside h('article', {class: 'prose'}), then previous/next chapter buttons. Unknown id: back to the list.
