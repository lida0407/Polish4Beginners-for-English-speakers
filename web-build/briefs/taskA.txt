--- session.js (#/session/<kind>/<value>) ---
The flashcard study loop, full screen (call ctx.focusMode(true) on every render).
Deck building, once, into ctx.state.deck (and index = 0, revealed = false, known = 0, done = false):
- kind 'topic': cards with level === settings().level and (value === 'All' or category === value). Order: cards with statusOf === 1 (due) shuffled, then statusOf === 0 (new) shuffled; if that pool is empty use the learnt ones sorted by memOf(card).dueAt ascending. Take the first 10.
- kind 'all': every card of category === value at the level, shuffled.
- kind 'status': every card (any level) with statusOf(card) === Number(value), shuffled, at most 50.
- kind 'fav': favourites() (items may lack id).
- kind 'list': the items of the list named value ({polish, english} only).
Also pick per card whether the English side is shown first (random boolean, stored in state so it survives refresh).
Screen:
- A .spread row: ui.progress(index / deck.length) taking the width, the text `card ${index + 1} / ${deck.length}`, and a close link (<a class="back" href="#/home">×</a>).
- The flashcard: ui.card({class: 'flash', onclick: reveal}). Before reveal: the front text (.flash-front; Polish via ui.pl when Polish is the front) and the hint 'Odwróć kartę · tap to flip' (.flash-hint). After reveal: Polish (.flash-front, as tappable(polish, {tag: 'div'})), phonetic, english (.flash-back), then if present the example (tappable(examplePolish) + english in muted small), card.notes, and the learner's own note (L.notePreview(noteFor(polish), 160)) labelled 'Your note'.
- Tools row (.hstack, centred): phraseTools(card), ui.button('Read PL', {small: true}) -> speak(card.polish), ui.button('More', {small: true}) -> openWord(card).
- Buttons: before reveal one ui.button('Pokaż odpowiedź · show answer', {kind: 'primary', block: true}); after reveal two side by side: 'Jeszcze nie · not yet' (ghost) and 'Umiem! · got it' (lime). Grading: if the card has an id call grade(card, got); count known; move to the next card (revealed = false); after the last card set done = true.
- Keyboard: Space or Enter flips; after reveal, 1 or ArrowLeft = not yet, 2 or ArrowRight = got it. Add ONE keydown listener on document (guard with a flag in ctx.state), ignore events whose target is an input/textarea/select, and remove it in ctx.onLeave. The handler must read the latest ctx.state and call ctx.refresh().
- Finish screen (done): kicker 'Well done!', h1 'Lesson finished', `${known} of ${deck.length} known`, buttons 'Again' (clear ctx.state keys so the deck is rebuilt, refresh) and 'Back home'.
- Empty deck: ui.empty('Nothing to study here yet.', a Back home button).
